# React + Vite Starter

Look at the [Vite documentation](https://vite.dev/guide/) and [React documentation](https://react.dev/learn) to learn more.

## Setup

```bash
pnpm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
pnpm dev
```

## Production

```bash
# 빌드
pnpm build

# 빌드 결과 미리보기
pnpm preview
```
